# 📱 CODSOFT_TASKS

Android apps built in Kotlin during my Android App Development internship at CodSoft.

## 📌 Overview

This repo contains three separate Android projects, one per folder. Each app is a self-contained Android Studio project.

## 📂 Projects

| App | Description | Folder |
|-----|-------------|--------|
| **Quote of the Day** | Shows a daily quote loaded from a local JSON file | [`/QuoteOfTheDay`](./CODSOFT_TASK_NO_2) |
| **Quiz App** | Multiple categories, difficulty levels, final scoring, and a saved attempts history | [`/QuizApp`](./CODSOFT_TASK_NO_4) |
| **To-Do List** | Add and manage daily tasks | [`/ToDoList`](./CODSOFT_TASK_NO_1) |

## ✨ Key Features

**Quote of the Day**
- Quotes loaded from a local JSON file
- Daily refresh / random quote / share button, if applicable

**Quiz App**
- Multiple categories and difficulty levels
- Final score at the end of each quiz
- Saved attempts history

**To-Do List**
- Add, edit, delete, mark complete, local storage, if applicable

## 🛠️ Tech Stack

| Layer | Technology |
|-------|------------|
| Language | Kotlin |
| IDE | Android Studio |
| UI | [XML layouts / Jetpack Compose] |
| Storage | [Room / SharedPreferences / SQLite] |
| Data | JSON (Quote app) |

## 🚀 How to Run

1. Clone the repo: `git clone https://github.com/ShakaByte/CODSOFT_TASKS.git`
2. Open Android Studio and choose **Open**, then select one app's folder (e.g. `QuizApp`)
3. Let Gradle sync
4. Run on an emulator or a physical device
